# 🎛️ 控制台速查手册

浏览器打开 `http://localhost:8080` (默认端口) 即可访问 Web 控制台。以下按区域逐一说明所有控件。

## 📝 KV 操作

位于**控制操作**面板左列顶部，标题 `KV 操作` 右侧实时显示当前 Key 的哈希分片提示（`→ 分片X`）。

| 控件                    | 说明                                 |
|-----------------------|------------------------------------|
| **Key** 输入框（Put 侧）    | 输入要写入的键，右侧实时显示分片哈希提示               |
| **Value** 输入框         | 输入要写入的值                            |
| **Put**               | 写入键值对（携带版本号的 CAS 写入，版本不匹配时返回冲突）    |
| **Key** 输入框（Get 侧）    | 输入要读取的键                            |
| **Get**               | 根据 Key 读取对应值及其版本号                  |
| **随机键值** 下拉框 + **生成** | 选择目标分片后自动填入一个映射到该分片的 Key 和随机 Value |

操作结果实时显示在下方的结果区域，并记录到右侧**操作日志**。


## ⚡ CAS 竞争写入

基于版本号的乐观锁并发控制演示

| 控件                    | 说明                        |
|-----------------------|---------------------------|
| **Key** 输入框           | 要竞争写入的目标 Key，右侧实时显示分片提示   |
| **随机键值** 下拉框 + **生成** | 选取目标分片后自动填入随机 Key         |
| **客户端数** 输入框          | 并发请求数（1 ~ Clerk 池容量，默认 5） |
| **开始**                | 启动 N 个并发 CAS Put 请求       |

结果面板显示：✅ 成功数、⚠️ 版本冲突数、🏆 最终值、⏱️ 总耗时。


## 📦 批量随机写入

高并发批量写入测试。

| 控件           | 说明                                |
|--------------|-----------------------------------|
| **写入数量** 输入框 | 1~10000 个随机 Key（默认 100）           |
| **目标分片** 下拉框 | 指定分片或「任意」分片                       |
| **开始**       | 从 Clerk 池借用多个客户端并发写入 （先读，再基于版本号写） |

结果面板显示：成功数 / 失败数 / 总耗时。


## 🏗️ 组操作

位于**控制操作**面板右列顶部，标题 `组操作`。

| 控件         | 说明                          |
|------------|-----------------------------|
| **组** 下拉框  | 选择要操作的分片组（动态更新）             |
| **启动**     | 启动组内全部节点                    |
| **终止**     | 终止组内全部节点                    |
| **移除**     | 让组离开集群，分片自动迁移至其他组（配置仓库不可移除） |
| **+ 新组加入** | 创建一个新的分片组加入集群，触发分片自动迁移      |


## 🌐 不可靠网络

位于**控制操作**面板右列中部。

| 控件           | 默认值      | 说明                                                    |
|--------------|----------|-------------------------------------------------------|
| **开关**       | 关闭       | 主开关，关闭时所有滑块禁用（半透明），开启后才可调节                            |
| **丢包率**      | 10%      | RPC 请求/回复被随机丢弃的概率，滑块范围 0%~100%                        |
| **RPC 请求延迟** | 0~27ms   | 每个 RPC 请求附加的随机延迟，最大范围 0~500ms                         |
| **RPC 回复乱序** | 关闭       | 开关控件，开启后 2/3 的 RPC 回复被延迟 200~2200ms，模拟 TCP 重传导致的旧消息晚到 |
| **断连延迟**     | 0~7000ms | 节点隔离/终止时，其他节点等待 RPC 回复的最大超时时间，最大范围 0~10000ms          |


## 🔭 观测日志开关

位于**控制操作**面板右列底部，标题 `观测日志`。此区域的复选框控制右侧**观测日志面板**中显示哪些类别的内部事件。

| 复选框        | 说明                     |
|------------|------------------------|
| **Raft选举** | 领导者选举、任期变更、投票过程、节点身份变更 |
| **Raft复制** | Leader 发送日志追加和安装快照     |
| **Raft快照** | 状态机压缩为快照、节点重启后从快照恢复    |
| **KV操作**   | 键值读写提交、去重、版本变化、重试机制    |
| **分片迁移**   | 分片迁移的冻结/安装/删除三阶段       |


## 🗺️ 节点状态面板

控制台中部的卡片区域，展示所有分片组（含配置仓库）的节点拓扑。

### 标题栏

| 元素            | 说明                              |
|---------------|---------------------------------|
| **节点状态**      | 面板标题                            |
| **+ 新组加入**    | 快捷添加新分片组                        |
| **刷新信息**      | 居中显示上次刷新时间等状态信息                 |
| **⚠ 分片迁移未完成** | 右侧黄色圆形徽章，有未完成的分片迁移时显示，迁移完成后自动隐藏 |

### 组卡片

每个组一张卡片，左侧有颜色边条标识，组间颜色按编号循环分配。

| 元素      | 说明                                                          |
|---------|-------------------------------------------------------------|
| **组名**  | `配置仓库` 或 `组 X`                                              |
| **分片数** | 仅非配置仓库组显示，格式 `(N 分片)`                                       |
| **日志**  | 切换该组的观测日志过滤（是否显示该组事件）                                       |
| **混沌**  | 自动故障注入开关；灰色「混沌」→ 启动，红色「混沌中」→ 进行中，每 1~3s 随机 Kill 节点（保证多数派在线） |
| **移除**  | 让该组离开集群（仅非配置仓库组可见）                                          |

### 节点行

每个节点一行，包含状态指示灯、名称、状态文字和操作按钮。按钮随节点状态动态显示。

**状态指示灯：**

| 灯的颜色    | 含义              |
|---------|-----------------|
| 🟢 发光绿点 | 领导者节点（绿色光晕效果）   |
| 🟢 普通绿点 | 在线跟随者           |
| 🔴 红点   | 离线（已终止）         |
| 🟡 黄点   | 网络隔离            |
| 🟡 发光黄点 | 被隔离的领导者节点（黄色光晕） |

**节点操作按钮：**

| 按钮     | 出现条件      | 说明                      |
|--------|-----------|-------------------------|
| **隔离** | 节点在线且未被隔离 | 切断节点网络连接（进程仍在运行），模拟网络分区 |
| **恢复** | 节点在线且已被隔离 | 恢复被隔离节点的网络连接            |
| **终止** | 节点在线      | 杀死节点进程，模拟节点宕机           |
| **启动** | 节点离线      | 重新启动已终止的节点，自动连入集群同步数据   |

**状态文字：**

| 显示文字       | 含义         |
|------------|------------|
| Leader  在线 | 领导者节点，正常运行 |
| 在线         | 跟随者节点，正常运行 |
| 离线         | 节点已终止      |
| 隔离         | 节点网络被隔离    |
| Leader  隔离 | 领导者节点被隔离   |


## 📊 分片分布面板

展示 12 个分片到各分片组的映射关系，每个分片卡片用所属组的颜色标识。

| 控件             | 说明                                |
|----------------|-----------------------------------|
| **按分片排序** （默认） | 分片 0~11 依次排列                      |
| **按组排序**       | 分片按所属组归类排列，同组数据集中显示               |
| **信息栏**        | 显示 `共 X 个分片 · Config #N`（当前配置版本号） |

当配置仓库离线时，面板显示 `ConfigStore 离线，分片分布不可用`。


## 📋 操作日志

记录所有操作结果，不同颜色标识不同消息类型：

| 颜色    | 类型          | 使用场景                                                     |
|-------|-------------|----------------------------------------------------------|
| 🟢 绿色 | 操作成功        | Put/Get 读写成功、节点启动成功、混沌停止、组加入/离开完成、批量写入/CAS 竞赛完成          |
| 🔴 红色 | 操作失败或动作记录   | 读写失败、节点/组操作失败、API 异常 —— 也用于记录操作行为（如终止节点/组、隔离、开启混沌/不可靠网络） |
| 🟡 金色 | 警告 / 参数校验失败 | Key 为空、写入数量超限、选择无效组、配置仓库 不可移除                            |
| 🔵 蓝色 | 一般信息 / 处理中  | 系统就绪、开始执行操作、填入随机键值对、正在处理中                                |

日志面板特性：

| 特性        | 说明                                 |
|-----------|------------------------------------|
| **时间戳**   | 每条日志前显示 `[HH:MM:SS]`               |
| **收起/展开** | 点击标题栏切换，按钮文字「收起」↔「展开」              |
| **拖拽调整**  | 标题栏下方的拖拽手柄（`···`）可上下调整与观测日志面板的分割比例 |
| **保留限制**  | 保留最近 200 条记录，超出后自动删除最旧的            |
| **自动滚动**  | 新日志追加时自动滚动到底部                      |


## 🔭 观测日志面板

右侧面板的下半部分，系统内部事件的实时日志。

| 元素        | 说明                    |
|-----------|-----------------------|
| **标题**    | `观测日志`，点击可展开/收起       |
| **清空**    | 清空当前显示的观测日志，后续新日志继续追加 |
| **展开/收起** | 标题栏右侧按钮切换             |

### 事件标签颜色

每条日志按标签着色标签文本：

| 标签         | 事件内容                   |
|------------|------------------------|
| **Raft选举** | 领导者选举、任期变更、投票过程、节点身份变更 |
| **Raft复制** | Leader 发送日志追加和安装快照     |
| **Raft快照** | 状态机压缩为快照、节点重启后从快照恢复    |
| **KV操作**   | 键值读写提交、去重、版本变化、重试机制    |
| **分片迁移**   | 分片迁移三阶段                |

### 正文颜色

| 场景     | 颜色    | 说明                        |
|--------|-------|---------------------------|
| 分片迁移冻结 | 🔵 冰蓝 | `冻结 (Freeze)` — 旧组停止接受写入  |
| 分片迁移安装 | 🟢 绿色 | `安装 (Install)` — 新组安装分片数据 |
| 分片迁移删除 | 🟠 琥珀 | `删除 (Delete)` — 旧组清理旧副本   |
| 故障/恢复  | 🔴 红色 | 发生故障或从故障中恢复的事件            |
| 其他     | 默认    | 无特殊着色                     |

### 组过滤

- 通过各**组卡片**上的 **日志** 按钮切换该组的观测日志过滤
- 配置仓库（组 0）默认关闭，其他分片组默认开启
- 日志正文前带有 `[CS]`、`[G1]`、`[G2]` 等组标签用于识别来源
