# 🎛️ 控制台速查手册

浏览器打开 `http://localhost:8080` 即可访问 Web 控制台。以下按区域逐一说明所有控件。

---

## 📝 KV 操作

| 控件 | 说明 |
|------|------|
| **Key / Value** 输入框 | 输入键值对，右侧实时显示 `→ 分片X` 哈希提示 |
| **Put** | 写入键值对（携带版本号的 CAS 写入，版本不匹配时返回冲突） |
| **Get** | 根据 Key 读取对应值及其版本号 |
| **随机键值** 下拉框 + **生成** | 选择目标分片后自动填入一个映射到该分片的 Key 和随机 Value |

操作结果实时显示在下方的结果区域，并记录到右侧**操作日志**。

---

## ⚙️ 节点操作

每个节点卡片上显示状态指示灯和可用操作按钮（按钮随状态动态显示）：

| 按钮 | 状态点 | 说明 |
|------|--------|------|
| **隔离** | 🟡 | 切断节点网络连接（进程仍在运行），模拟网络分区 |
| **恢复** | 🟢 | 恢复被隔离节点的网络连接 |
| **终止** | 🔴 | 杀死节点进程，模拟节点宕机 |
| **启动** | 🟢 | 重新启动已终止的节点，自动连入集群同步数据 |

节点状态指示灯：

| 状态点 | 含义 |
|--------|------|
| 🟢 **发光绿点** | 领导者节点（带光晕效果） |
| 🟢 **普通绿点** | 在线跟随者 |
| 🔴 **红点** | 离线（已终止） |
| 🟡 **黄点** | 网络隔离 |
| 🟡 **发光黄点** | 被隔离的领导者节点 |

---

## 🏗️ 组操作

位于**控制操作**面板右上区域，下拉框选择组后操作：

| 按钮 | 说明 |
|------|------|
| **启动** | 启动组内全部节点 |
| **终止** | 杀死组内全部节点 |
| **移除** | 让组离开集群，分片自动迁移至其他组（ConfigStore 不可移除） |
| **+ 新组加入** | 创建一个新的分片组加入集群，触发分片自动迁移 |

组卡片上的控件：

| 控件 | 说明 |
|------|------|
| **混沌** | 启动/停止该组的自动故障注入（每 1~3s 随机 Kill 节点，保证多数派在线） |
| **移除** | 让该组离开集群（仅非 ConfigStore 组可见） |
| **日志**按钮 | 切换该组的观测日志过滤（只显示该组事件） |

---

## 🌐 不可靠网络

位于组操作下方，开关控制，开启后调节以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **丢包率** | 10% | RPC 请求/回复被随机丢弃的概率，滑块 0%~100% |
| **RPC 请求延迟** | 0~27ms | 每个 RPC 请求附加的随机延迟 |
| **RPC 回复乱序** | 关闭 | 开启后 2/3 的 RPC 回复被延迟 200~2200ms，模拟 TCP 重传导致的旧消息晚到 |
| **断连延迟** | 0~7000ms | 节点隔离/终止时，其他节点等待 RPC 回复的最大超时时间 |

参数滑块在不可靠网络关闭时自动禁用（半透明），开启后才可调节。

## ⚡ CAS 竞争写入

基于版本号的乐观锁并发控制演示：

| 控件 | 说明 |
|------|------|
| **Key** 输入框 | 要竞争写入的目标 Key |
| **随机键值** + **生成** | 选取目标分片后自动填入随机 Key |
| **并发客户端数** 输入框 | 并发请求数（上限由后端 Clerk 池容量决定） |
| **开始** | 启动 N 个并发 CAS Put 请求 |

结果面板显示：✅ 成功数、⚠️ 版本冲突数、🏆 最终值、⏱️ 总耗时。

---

## 📦 批量随机写入

高并发批量写入测试：

| 控件 | 说明 |
|------|------|
| **写入数量** 输入框 | 1~10000 个随机 Key |
| **目标分片** 下拉框 | 指定分片或「任意」分片 |
| **开始** | 从 Clerk 池借用多个客户端并发写入 |

结果面板显示：成功数 / 失败数 / 总耗时。

---

## 🗺️ 节点状态面板

控制台中部的卡片区域，展示所有分片组及配置仓库的节点。标题行显示组名和分片数，右侧有操作按钮。

| 元素 | 说明 |
|------|------|
| **⚠ 分片迁移未完成** | 黄色徽章，迁移完成后自动消失 |
| **日志**按钮 | 点击后只查看该组观测日志，过滤其他组噪音 |
| **混沌**按钮 | 自动故障注入开关（变红「混沌中」表示进行中） |

---

## 📊 分片分布面板

展示 12 个分片到各组的映射关系：

| 按钮 | 说明 |
|------|------|
| **按分片排序** | 分片 0~11 依次排列（默认） |
| **按组排序** | 分片按所属组归类排列，同组数据集中展示 |

信息栏显示 `共 X 个分片 · Config #N`（当前配置版本号）。

---

## 📋 操作日志

右侧日志面板，记录所有操作结果：

- 绿色文字：操作成功
- 红色文字：操作失败或异常
- 支持**拖拽调整**宽度和高度
- 可**收起/展开**

---

## 🔭 观测日志

系统内部事件 SSE 实时推送，支持 5 类事件筛选：

| 标签 | 事件内容 |
|------|---------|
| **Raft选举** 💙 | 领导者选举、任期变更、投票过程、节点身份变更 |
| **Raft复制** 🩷 | Leader 发送日志追加和安装快照 |
| **Raft快照** 💜 | 状态机压缩为快照、节点重启后从快照恢复 |
| **KV操作** 💚 | 键值读写提交、去重、版本变化、重试机制 |
| **分片迁移** 🧡 | 冻结/安装/删除三阶段，各阶段颜色编码不同 |

迁移子类型颜色编码：

| 阶段 | 颜色 | 说明 |
|------|------|------|
| **冻结 (Freeze)** | 🔵 冰蓝 | 旧组停止接受写入 |
| **安装 (Install)** | 🟢 绿色 | 新组安装分片数据 |
| **删除 (Delete)** | 🟠 琥珀 | 旧组清理旧副本 |

支持**清空**、**拖拽调整大小**、每个组独立过滤。
